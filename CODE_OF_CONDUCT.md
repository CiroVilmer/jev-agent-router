# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part — in issues, pull requests, discussions or any
other project space — is expected to follow it.

In short: be respectful and welcoming, give and accept constructive feedback gracefully, and
focus on what is best for the community. Harassment, insults, and publishing others' private
information are not acceptable.

## Reporting

Report unacceptable behavior by [opening an issue](https://github.com/CiroVilmer/jev-agent-router/issues/new).
If the matter is sensitive, don't include details in the issue: just ask the maintainer for a
private channel, and the conversation will continue there. Reports are reviewed promptly and
handled confidentially.

Enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
